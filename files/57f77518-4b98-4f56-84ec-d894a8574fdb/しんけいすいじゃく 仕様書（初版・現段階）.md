# しんけいすいじゃく 仕様書（初版・現段階）

Oct 25, 2026 · @Takumi Muraishi

## 概要

小さな子どもが、1人でも、親や祖父母と一緒でも遊べる、広告なしの神経衰弱アプリ（iPhone）。初版は、「どうぶつ」と「ひらがな」の2つのコースで、絵とひらがなを、遊びながら覚えられる。

| 項目 | 内容 |
| --- | --- |
| アプリ名（仮） | しんけいすいじゃく |
| 対象 | 小さな子ども、一緒に遊ぶ親や祖父母 |
| コンセプト | 急かさない、広告なし、すぐ遊べる |
| 対応端末 | iPhone（小さな画面でも遊べること） |
| 収益 | 買い切りのパス1本（¥100）。広告はなし |
| 公開のしかた | 子ども向けカテゴリ |
| 元になった試作 | Web版の「かんたん神経衰弱」と、初版の試作（リンクは最後の節） |

## 初版（最初の公開）の範囲

最初の公開は、範囲を絞って、早く出して、反応を見る。

| 区分 | 内容 |
| --- | --- |
| 含めるもの | どうぶつコース、ひらがなコース、スタンプちょう、¥100の買い切りパス、おうちの方への画面 |
| 含めないもの | かずコース、かたちコース、音声（読み上げ） |
| 音声 | 入れない。録音が要らないので、すぐ作れる。ひらがなは、文字と言葉を画面に出し、親が声に出して読んであげる使い方を想定する |
| あとの更新で足す案 | かずコース、かたちコース、録音した音声（詳しくは「あとの更新で足すもの」の節） |

## 基本方針

子どもが1人でも安心して遊べることを、機能より優先する。使ってもらうことを、収益より優先する。

1. 広告を一切出さない。第三者の広告と分析ツールは入れない。
2. 急かさない。タイマー、制限時間、めくった回数、ミスの表示は出さない。
3. すぐ遊べる。初めて開いたときは、ホームを通らず、6ペアのゲームがすぐ始まる。最初の1回をクリアするまでは、開くたびにゲームから始まり、2回目以降はホームから始まる。
4. 子ども向けの画面の文字は、原則ひらがなにする。
5. 個人情報を集めない。アカウント登録とログインは用意しない。
6. 購入、設定、外部へのリンクは、保護者の確認を通したあとだけにする。
7. ハズレを責めない。めくったカードが自然に裏返るだけで、×表示や警告音は出さない。

## 画面と遷移

画面は、ホーム、プレイ、クリア、スタンプちょう、おうちの方への5つ。このほかに、コース選択のダイアログと、保護者の確認のダイアログがある。

&#91;embedded content: 画面の遷移・ホームを入り口にした流れ\]

ホームが入り口で、遊ぶ、スタンプを見る、購入する、の3つの道へつながる。

| 画面 | 目的 | 主な要素 | 遷移先 |
| --- | --- | --- | --- |
| 起動（最初の1回をクリアするまで） | 迷わずに遊び始める | ホームを出さず、どうぶつ（やさしい・6ペア）のゲームをすぐ開始。最初に全カードを見せる時間を長め（約5秒）にする | プレイ |
| ホーム | 「あそぶ」を押すだけで始める | 大きな「あそぶ」（前回の続き）、ひらがなのタイトル、動物4匹のアーチ、「ほかのあそびかた」の2コース、スタンプちょうのボタン、右上の「おうちの方へ」。広告はなし | プレイ、コース選択、スタンプちょう、おうちの方へ |
| コース選択（ダイアログ） | 難易度を選ぶ | やさしい（6ペア）、ふつう（8ペア）、むずかしい（10ペア）。ふつうとむずかしいには、鍵のマークが付く（購入後は消える） | プレイ、保護者の確認 |
| プレイ | ペアを探して遊ぶ | カード4列、「あと◯ペア」、「ヒント」「やめる」。タイマー、回数、音声はなし | クリア、ホーム（「やめる」は確認のあと） |
| クリア | ほめて、次の遊びにつなげる | 「よくできました！」、新しいスタンプ1つ。点数や回数は出さない。ボタンは、もう一回、次の難易度、スタンプちょう、ホーム、「もっと むずかしいのは おうちの方へ」 | プレイ、スタンプちょう、ホーム、保護者の確認 |
| スタンプちょう | 集めた数を見て楽しむ | 通常の枠12個、パス専用の枠4個、集めた数 | ホーム |
| おうちの方へ | 購入と方針の説明 | 保護者の確認（簡単な計算）、パスの内容と価格、購入、広告なし・個人情報を集めない方針 | ホーム |

プレイ画面の「やめる」は、「やめますか？」と確認してから、ホームへ戻る。

### ロックされた難易度を押したとき

1. 子どもが、鍵のマークが付いた難易度（ふつう、むずかしい）を押す。
2. 「おうちの方に あけてもらってね」と、ひらがなで案内する。値段と購入の画面は、子どもには見せない。
3. 「おうちの方へ」を押すと、簡単な足し算で、保護者の確認をする。間違えたときは、別の問題に変わる。
4. 合っていたら、パスの内容と価格（¥100）を表示する。「購入する」で購入する。
5. 購入が終わったら、押した難易度のゲームがすぐ始まる。

確認をやめたときは、ホームに戻る。購入の案内を、くり返し出さない。

## コースとゲームルール

初版のコースは2つ。どちらも、やさしい（6ペア）は何度でも無料で、ふつう以上はパスの購入後に遊べる。

| コース | あそび方 | 無料の範囲 |
| --- | --- | --- |
| どうぶつ | 同じ絵のペアを探す。絵は、ネコ、キツネ、パンダ、カエル、リンゴ、ヒヨコ、ペンギン、ウサギ、イヌ、イチゴの10種類から選ぶ | やさしいは何度でも無料 |
| ひらがな | 文字のカードと、絵のカードをペアにする（下の10組から選ぶ） | やさしいは何度でも無料 |

### ひらがなコースの10組

| 文字 | 絵 | 言葉 |
| --- | --- | --- |
| ね | ネコ | ねこ |
| か | カエル | かえる |
| き | キツネ | きつね |
| り | リンゴ | りんご |
| す | スイカ | すいか |
| ひ | ヒヨコ | ひよこ |
| ほ | ホシ | ほし |
| う | ウサギ | うさぎ |
| い | イヌ | いぬ |
| く | クマ | くま |

- 濁点や半濁点のある字は、小さな子には難しいため使わない。
- 文字のカードは温かい色の地、絵のカードは水色の地にする。ペアが揃うと緑色になり、絵のカードに言葉が現れる。
- 初版では、音声を入れない。親が声に出して読んであげる使い方を想定する。
- 文字は、丸みのある書体（ヒラギノ丸ゴ）の大きな字にする。

### ゲームルール（共通）

- 難易度は、やさしい（6ペア）、ふつう（8ペア）、むずかしい（10ペア）の3つ。カードは4列で並べる。
- 毎回、候補の中から必要な数をランダムに選び、カードの位置もランダムにする。
- 始めに、全てのカードを数秒見せてから裏返す。6ペアは約2.6秒、8ペアは約3.0秒、10ペアは約3.4秒。最初の1回だけ、約5秒にする。
- ヒントは、押すと約1秒だけ全カードを見せる。回数の制限はなし。
- ハズレの2枚は、約0.9秒で裏返る。×表示や警告音は出さない。
- 「あと◯ペア」を画面の上部に表示する。タイマー、めくった回数、ベスト記録は表示しない。

### 無料とパスの分け方

- やさしい（6ペア）は、2つのコースとも、何度でも無料。
- ふつうとむずかしいは、パスの購入後に遊べる。鍵のマークを付ける。
- クリアのあとに、「もっと むずかしいのは おうちの方へ」と、控えめに案内する。購入の画面には、自動で進まない。
- パスを購入したあとは、鍵のマークと案内を消す。

## スタンプ

クリアするたびに、スタンプが1つ増える。続けて遊びたくなる仕掛けで、急かす要素は入れない。

| 種類 | 数 | 内容 |
| --- | --- | --- |
| 通常のスタンプ | 12個 | ネコ、イヌ、ウサギ、パンダ、カエル、ヒヨコ、キツネ、ペンギン、リンゴ、イチゴ、クマ、スイカの絵を、1つずつ |
| パス専用のスタンプ | 4個 | ふつうをクリアすると銀のふち、むずかしいをクリアすると金のふちの、コースのシンボル（どうぶつ：ネコ、ひらがな：「あ」）のスタンプ。2コース×2段階で4個 |

- 通常のスタンプは、クリアするたびに、まだ持っていないものの中から、1つをランダムにもらえる。全部そろったあとは、新しいスタンプは増えず、ほめ言葉だけを出す。
- パス専用のスタンプは、パスを購入したあとで、ふつうやむずかしいをクリアしたときにもらえる。購入前は、鍵のマークの枠で示す。
- まだ手に入っていない枠は、点線の丸で示す。
- 集めた数を、「5 / 12」のように表示する。
- 期限、連続日数、ランキングは設けない。
- スタンプの記録は、端末の中だけに保存し、外部へは送らない。

## 収益・課金

収益は、買い切りの「ぜんぶ遊べるパス」1本だけ。広告はどこにも出さない。収益より、使ってもらうことを優先する。

| 項目 | 内容 |
| --- | --- |
| 販売形態 | 買い切り、1本。月額はなし |
| 価格 | ¥100。App Store Connectで選べる価格を確認して確定する（¥100がない場合は、近い価格にする） |
| 無料の範囲 | 2つのコース（どうぶつ・ひらがな）の、やさしい（6ペア） |
| パスの内容 | 2つのコースの、ふつう・むずかしいが遊べる。パス専用のスタンプも集められる |
| 購入の入口 | 鍵のマークが付いた難易度を押す、または「おうちの方へ」。起動時や遊んでいる途中には、購入の案内を出さない |
| 購入の確認 | 簡単な計算による、保護者の確認のあとだけ |
| 復元 | 「購入を復元」を用意する |

見込みは概算。税込¥100から、消費税10%と、AppleのSmall Business Program適用後の手数料15%を引くと、手元に残るのは1本あたり約¥77。このパスだけで月間¥100,000を稼ぐには、毎月1,300本前後が必要になる。収益の柱ではなく、副収入または実績づくりとして見る。税の扱いと条件は、申請時に最新の情報を確認する。

## デザイン方針

絵はフラットに統一する。細めの輪郭線と、軽いゆらぎを付け、明るくはっきりした色を使う。

| 項目 | 内容 |
| --- | --- |
| 絵の種類 | ネコ（グレー）、イヌ（茶）、ウサギ（白）、パンダ（白黒）、カエル（緑）、ヒヨコ（黄）、キツネ（オレンジ）、ペンギン（青）、リンゴ（赤）、イチゴ（ベリー色）。ひらがなコースでは、さらに、クマ（茶）、スイカ（緑と赤）、ホシ（黄）を使う。イヌとクマは、どちらも茶色系なので、耳の形で見分ける |
| カードの裏 | 薄い青に、白い水玉。「？」は、地より濃い青 |
| 強調色 | 青。ボタンや「あと◯ペア」の数字に使う |
| ホーム | 青い水玉の背景、色違いのひらがなのタイトル、動物4匹のアーチ、大きな「あそぶ」ボタン |
| ヒントのアイコン | 動物たちと同じタッチの、目のイラスト |
| クリアの絵 | スタンプを大きく表示する |
| タップできる大きさ | 44pt以上 |
| 文字 | 子ども向けの画面は、ひらがなを基本にする。ひらがなコースの文字は、丸みのある書体（ヒラギノ丸ゴ）にする |
| 表示モード | ライトとダークの両方に対応する |

## 技術と対応環境

iOSネイティブアプリとして作り直す。通信なしで遊べ、データは端末の中だけに保存する。

- 開発方式は、SwiftUIを想定（案）。Web版と、初版の試作は、仕様の確認のためのものとして扱う。
- 課金は、買い切りの非消耗型を1つ（StoreKit）。購入状態の復元に対応する。
- 保存するものは、スタンプの記録、購入状態、前回遊んだコースと難易度、最初の1回をクリアしたかどうか。アカウントと外部送信はなし。

| 項目 | 案 |
| --- | --- |
| 端末 | iPhone。iPadでは、iPhone用の画面がそのまま使える形で出す。専用の画面は作らない |
| 画面の向き | 縦向きのみ |
| 最低のiOS | 未決。作る時点で、広く使われている版に合わせる |
| 言語 | 日本語のみ |
| 画面の大きさ | 小さな画面（iPhone SE相当）でも、スクロールなしで遊べる |
| 読み上げ支援（VoiceOver） | カードと「あと◯ペア」を、読み上げられるようにする |
| 色だけに頼らない | 絵の名前（ひらがなコースの言葉）で、色以外の手がかりも示す |
| 動きの設定 | 「視差効果を減らす」などの設定がオンのときは、カードのめくりを控えめにする |

## 公開時の注意

子ども向けカテゴリで出す（決定）。Appleのルールを満たす必要がある。申請前に、App Store Review Guidelinesの1.3と5.1.4を、最新版で確認する。

- 子ども向けカテゴリでは、第三者の広告と分析ツールを入れない方針とする。このアプリは広告なしのため、この点は満たしやすい。
- 外部サイトへのリンク、購入、権限の要求は、保護者の確認（親ゲート）を通したあとだけにする。
- 「子ども向け」などの語は、子ども向けカテゴリ用とされている。このアプリはカテゴリで出すので、説明文などで使える。
- 一度このカテゴリで出すと、あとから外すのは難しいため、広告や分析ツールは、今後も入れない。
- 年齢区分は、子ども向けカテゴリの区分から選ぶ。5歳以下を中心に想定する（案）。App Store Connectで確認する。
- プライバシーに関する法律の扱いは、必要に応じて専門家に確認する。

申請の前に、次のものを用意する。

- プライバシーポリシーのURL。「個人情報を集めない」ことを、はっきり書く。
- App Privacy（収集するデータの申告）と、年齢制限の質問票。
- アプリ名、サブタイトル、説明文、スクリーンショット。
- 課金（購入と復元）のテスト。
- アプリ名が、すでに使われていないかの確認。商標の確認も含める。

## あとの更新で足すもの

初版には入れないが、すでに試作で確かめた内容を、ここにまとめる。足すときは、この内容を元にする。

### かずコース

数字のカードと、その数だけ同じ絵が並んだカードをペアにする。

- 難易度ごとの数の範囲は、やさしい（1〜6）、ふつう（1〜8）、むずかしい（1〜10）。最大は10。
- 1回のゲームで数える絵は、全部同じ1種類にする。種類は、リンゴ、ヒヨコ、パンダ、カエル、キツネの中から、ゲームごとに1つ選ぶ。数ではなく、絵の種類でペアを決めてしまわないようにするため。
- 絵は、カードいっぱいに大きく表示する。数に応じて、いちばん大きく見える並べ方を自動で選ぶ。

### かたちコース

灰色の影の形のカードと、同じ形の色つきの図形をペアにする。「いろ」のペアは扱わない。青リンゴや三毛猫のように、ものの色が1つに決まらず、ペアの答えが1つにならないため。

- 形は12種類。まる、さんかく、しかく、ながしかく、ほし、ハート、ひしがた、だえん、はんえん、じゅうじ、ごかくけい、ろっかくけい。
- やさしい（6ペア）は基本の8種類の形から、ふつう（8ペア）は12種類の形から選ぶ。むずかしい（10ペア）は、動物と果物の影絵と、色つきの絵をペアにする。
- ペアが揃うと、名前（形や動物の名前）が現れる。

### 読み上げ（録音した音声）

足すときは、録音した音声ファイルを使う。端末の音声合成は、アクセントが不自然になることがあるため使わない。

| 種類 | 録音する言葉 |
| --- | --- |
| ひらがなの音（10） | ね、か、き、り、す、ひ、ほ、う、い、く |
| ひらがなの言葉（10） | ねこ、かえる、きつね、りんご、すいか、ひよこ、ほし、うさぎ、いぬ、くま |
| かず（10） | いち、に、さん、よん、ご、ろく、なな、はち、きゅう、じゅう |
| ほめ言葉（1以上） | よくできました |

- 声は標準語にする。アクセントは、録音の時点で確認して揃える。
- 録音の方法（ナレーターに依頼するか、音声合成で作った音声を使うか）は未決。音声合成を使う場合は、利用規約（商用利用、子ども向けアプリでの利用）を先に確認する。
- 音声ファイルは、アプリの中に入れ、通信なしで鳴らす。オン/オフは、プレイ画面のボタンで切り替える。
