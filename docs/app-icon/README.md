# しんけいすいじゃく アプリアイコン

## 決まったこと

- 絵：青い水玉の地に、裏のカード（「?」）と、表のカード（パンダ）の2枚を並べる。カードとパンダは、枠いっぱいに大きく置く。
- 種類：ライト（通常）、ダーク、ティントの3枚。ダークとティントは、iOS 18以降のホーム画面の表示で使われる。
- 対応端末：iPhoneのみ。iPad用の別のアイコンは、いらない。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `AppIcon.appiconset/` | Xcodeにそのまま入れられる形（`Contents.json` と、PNG 3枚） |
| `AppIcon.appiconset/AppIcon-1024.png` | ライト（通常） |
| `AppIcon.appiconset/AppIcon-1024-dark.png` | ダーク |
| `AppIcon.appiconset/AppIcon-1024-tinted.png` | ティント（白黒の濃淡だけ） |
| `source/` | 元になるSVG（3枚）。色や配置を変えるときだけ使う |
| `preview.png` | 3枚を並べた見本（iPhoneで見える角丸の形） |

3枚とも、1024×1024ピクセル、透明なしです。

## Xcodeへの入れ方

1. `AppIcon.appiconset` フォルダを、`Assets.xcassets` に入れて、もとの `AppIcon` と置き換える。
2. `AppIcon` を開いて、**Single Size** になっているか確かめる。
3. 3つの枠（Any Appearance／Dark／Tinted）に、次の画像が入っているか確かめる。入っていなければ、手で入れる。
   - Any Appearance：`AppIcon-1024.png`
   - Dark：`AppIcon-1024-dark.png`
   - Tinted：`AppIcon-1024-tinted.png`
4. ビルドして、ホーム画面で見え方を確かめる。

## 守ること

- **角を丸くしない**。PNGは、正方形のまま。角の丸みは、iPhoneが自動で付ける。
- **透明を含めない**。3枚とも、透明なし（RGB）。
- 大きさは、**1024×1024ピクセル**。
- 文字は入っていない。
- ティントの画像は、**白黒の濃淡だけ**。iPhoneは、明るさの差を元に、選んだ色を重ねる。

## 3枚の違い

| 種類 | 背景 | カード | 使われる場面 |
| --- | --- | --- | --- |
| ライト | `#2f6bd6`（青）に、白い水玉 | 裏 `#8fb7f9`、表 `#dce8f7` | 通常の表示。iOS 17では、いつもこれ |
| ダーク | `#0f1b33`（暗い青）に、白い水玉（透明度10%） | ライトと同じ。影だけ濃い | ダーク表示（iOS 18以降） |
| ティント | `#000000`（黒）に、白い水玉（透明度7%） | 裏 `#9c9c9c`、表 `#ececec`。パンダの濃い部分は `#1a1a1a` | 「色合い」表示（iOS 18以降） |

## 見た目の数値（作り直すとき用）

座標は、1024×1024の正方形で、左上が原点。3枚とも、同じ配置です。

| 要素 | 数値 |
| --- | --- |
| 左のカード（裏） | 中心 (325, 555)、幅410、高さ550、角丸42、左へ9度かたむける。白い水玉（透明度60%）を、46の間隔、半径6で並べる |
| 「?」 | 高さ約265、カードの中央。色 `#234fa5`（ライト、ダーク）、`#3a3a3a`（ティント） |
| 右のカード（表） | 中心 (705, 500)、幅410、高さ550、角丸42、右へ8度かたむける |
| パンダ | 表のカードの中央（やや下に6）。大きさは、絵の外形で約335。白 `#ffffff`、濃い色 `#222733` |
| 輪郭線 | カードは太さ10（色 `#2b3140`。ティントは `#111111`） |
| カードの影 | 下へ15ずらす |
| 背景の水玉 | 84の間隔、半径約10 |
| 重なり | 右のカード（表）が、左のカード（裏）の上 |

## 確認をお願いしたいこと

ティントの、色を重ねたときの見え方は、こちらでは確かめられていません。実機で、ホーム画面を「色合い」に切り替えて、見え方を確かめてください。
